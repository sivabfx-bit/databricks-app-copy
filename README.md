# Enterprise Data Intelligence Platform

An end-to-end enterprise data intelligence platform built with Databricks.

## Project capabilities

- Data ingestion from files and APIs
- Medallion architecture using Delta Lake
- Data transformation with PySpark and SQL
- Data quality and governance using Unity Catalog
- Workflow orchestration
- Business analytics and dashboards
- AI-powered business intelligence
- Databricks application development

## Technology stack

Databricks | Unity Catalog | Delta Lake | PySpark | SQL | GitHub | Python
